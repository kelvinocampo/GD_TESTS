# COMBAT SYSTEM (Práctica)

Este proyecto es una práctica de desarrollo enfocada en la implementación de un **sistema de combate** en Godot 4.

## 🎯 Objetivo
El objetivo principal es experimentar y asentar las bases de mecánicas de combate, movimiento y gestión de estados (vida, daño, experiencia), como paso previo al desarrollo de sistemas más complejos.

## 🎮 Características Actuales
- **Movimiento del Jugador:** Control fluido con WASD.
- **Sistema de Combate:**
  - Disparo direccional con el mouse.
  - Cambio de tipo de ataque (Fuego/Agua).
- **Enemigos:** IA básica de persecución (Slimes) que reciben daño y mueren.
- **Progresión:** Sistema simple de experiencia y subida de nivel.
- **UI:** Barras de vida y contador de nivel.

## 🕹️ Controles
- **W / A / S / D:** Moverse.
- **Click Izquierdo:** Atacar / Disparar.
- **Click Derecho:** Cambiar tipo de ataque.

## 🛠️ Tecnologías
- **Motor:** Godot Engine 4.x
- **Lenguaje:** GDScript
