# CRAFT & TRADE SYSTEM (Práctica)

Este proyecto es una práctica de desarrollo enfocada en la implementación de un **sistema de crafteo, inventario y comercio** en Godot 4.

## 🎯 Objetivo
El objetivo principal es experimentar y asentar las bases de mecánicas de gestión de recursos, crafteo de ítems, sistema de inventario y recolección de recursos, como paso previo al desarrollo de sistemas más complejos.

## 🎮 Características Actuales
- **Movimiento del Jugador:** Control fluido con WASD y teclas direccionales.
- **Sistema de Inventario:**
  - Gestión de ítems mediante slots.
  - UI de inventario con grid container.
  - Sistema de datos para ítems y slots.
- **Sistema de Crafteo:**
  - Recetas de crafteo con materiales requeridos.
  - UI de crafteo con visualización de ítems necesarios.
  - Validación de recursos disponibles.
- **Recolección de Recursos:** Interacción con recursos del mundo.
- **UI Modular:** Sistema de menús con toggles para inventario, crafteo y mapa.

## 🕹️ Controles
- **W / A / S / D:** Moverse.
- **Flechas Direccionales:** Moverse (alternativo).
- **I:** Abrir/Cerrar Inventario.
- **C:** Abrir/Cerrar Menú de Crafteo.
- **M:** Abrir/Cerrar Mapa.
- **E:** Interactuar con recursos/objetos.
- **Shift:** Movimiento rápido.

## 🛠️ Tecnologías
- **Motor:** Godot Engine 4.5
- **Lenguaje:** GDScript
